# 3udget katalog

Delt katalog med typiske danske husstands-udgifter og -indtægter til 3udget-appen. Priser er
vejledende gennemsnit — juster dem til din egen situation. `domain` (når sat) bruges til at hente
et logo via en offentlig favicon-tjeneste.

Se `editor/` for web-editoren til at redigere kataloget.
